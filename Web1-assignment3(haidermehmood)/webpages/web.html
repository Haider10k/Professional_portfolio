Rstimepieces Website Development

What is it?

This project was a website I had built and designed for my custom Seiko modding business, rsimepieces. Designed to showcase the brand and provide an easy way for customers to connect. The homepage includes an About Us section and quick contact links, giving visitors an introduction to the business and its purpose. The gallery page displays four different watch styles, each with a table outlining their specifications and components. The site also includes a dedicated contact page with additional information and a full contact form where customers can submit inquiries and communicate the details of their desired timepieces.

Tools used

HTML was used to build the entire structure of the website, including the header, navigation bar, content sections, gallery layout, and contact form. It provided the framework for:

  • About Us section
  • Product gallery
  • Watch specification table
  • Internal page linking and navigation
  • Contact form structure

HTML allowed the site to remain clean, semantic, and easy to navigate, which is especially important for a product-focused business website

CSS was used to define the visual identity and layout of the site, giving RSTimepieces a modern and professional appearance that reflects the branding of my business

  • Flexbox for consistent alignment
  • Spacing and structure images and content
  • Grid layout for the watch gallery
  • Responsive adjustments to improve readability and usability
  • Hover animations for links, icons, and interactive elements
  • Media queries for different devices, ensuring universal usage

Development Process

I began the project by creating wireframes to map the structure and layout of the website, using them as a blueprint to guide the overall design. Once the framework was clear, I built each page step-by-step and applied styling gradually, separating global styles from page-specific styles to reduce repeated code and keep the project organized

Obstacles Encountered

The website originally worked only on desktop screens, and several elements broke or shifted on smaller devices. Fixed sizes caused sections to overlap or misalign on tablets and phones, revealing the need for improved responsiveness and better use of media queries

How it was Solved

I implemented responsive media queries for desktop, tablet, and mobile sizes, adjusting layout, text, and image behaviour so the website could be accessed and viewed properly on any device
